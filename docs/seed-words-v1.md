# Seed Words v1 — 확장판

v0 시드에서 description 중복 충돌 해소를 위한 전면 확장.
HABITATS/FOODS/BEHAVIORS/TRIVIA 각 50개 이상 목표.
신규 카테고리 3개(SYMPTOMS, WEAKNESSES, LAST_SEEN) + 수식 레이어 2개(INTENSIFIERS, OCCUPATION_MODIFIERS) + TEMPORAL 추가.

## ADJECTIVES 수식 레이어 — INTENSIFIERS (10개)

> 형용사 앞에 약 30% 확률로 붙임. 짧고 강렬하게.

```js
const INTENSIFIERS = [

  "미친듯이",

  "은근히",
  "유독",
  "지금 막",
  "약간"
];

// 사용 예시:
// pick(INTENSIFIERS) + " " + pick(ADJECTIVES)
// → "존나 우울한", "갑자기 내향적인", "어쩐지 파인튜닝된"
// 적용 확률: 0.3 (30%)
```

## 생성 로직 의사코드

```js
function generateName() {
  const temporal = Math.random() < 0.15 ? pick(TEMPORAL) + " " : "";
  const intensifier = Math.random() < 0.30 ? pick(INTENSIFIERS) + " " : "";
  const adj = pick(ADJECTIVES);
  const noun = pick(NOUNS);
  const occMod = Math.random() < 0.40 ? pick(OCCUPATION_MODIFIERS) + " " : "";
  const job = pick(OCCUPATIONS);
  return `${temporal}${intensifier}${adj} ${noun} ${occMod}${job}`;
}

function generateDesc(name) {
  let lines = [
    `${name}는 ${pick(HABITATS)}에 산다.`,
    `주식은 ${pick(FOODS)}이며, ${pick(BEHAVIORS)}.`,
    `알려진 사실: ${pick(TRIVIA)}.`
  ];
  if (Math.random() < 0.40) lines.push(`주변 증상: ${pick(SYMPTOMS)}.`);
  if (Math.random() < 0.30) lines.push(`유일한 약점: ${pick(WEAKNESSES)}.`);
  if (Math.random() < 0.25) lines.push(`마지막 목격: ${pick(LAST_SEEN)}.`);
  return lines.join("\n");
}
```

## 판단 필요 항목

1. **TEMPORAL + INTENSIFIER 동시 적용** — 이름이 너무 길어질 수 있음 ("조선시대부터 있던 존나 우울한 토스터 전직 바리스타"). 둘 중 하나만 적용하는 OR 로직도 고려.
2. **SYMPTOMS/WEAKNESSES/LAST_SEEN 노출 방식** — 도감 카드에 항상 표시 vs 클릭해야 보이는 숨김 탭으로 처리?
3. **OCCUPATION_MODIFIERS 일부** ("사칭하는", "미등록") — 일부 조합에서 실제 직업 풍자처럼 읽힐 수 있음. 유지 여부 판단 필요.
